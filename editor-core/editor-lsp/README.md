# editor-lsp

Language Server Protocol 框架。负责协议模型、JSON-RPC、Transport、客户端与服务器生命周期、Server 注册和配置、能力协商、Workspace、文档同步、请求/通知、取消、错误处理及语言服务器接入。提供补全、诊断、悬停、跳转、引用、格式化、代码操作等语言服务适配，不负责编辑器 UI 和 Tree-sitter 解析。

This is an intentionally empty bootstrap module. No implementation classes or speculative dependencies are added yet.
