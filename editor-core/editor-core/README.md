# editor-core

一体化代码编辑器主体 View。负责文本编辑与存储、编辑事务、Undo/Redo、光标与选区、键盘和 IME 输入、布局、渲染、滚动、行号、折叠、搜索替换、补全交互、格式化结果应用、代码片段、剪贴板、装饰、编辑器状态与性能。Activity 负责 IDE 页面 UI；本模块不负责 Activity 页面、项目文件管理、Tree-sitter 实现或 LSP 协议。

This is an intentionally empty bootstrap module. No implementation classes or speculative dependencies are added yet.
