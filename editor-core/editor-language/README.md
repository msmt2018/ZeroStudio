# editor-language

语言解析与语法框架。负责语言注册与配置、Tree-sitter 集成、Parser/Tree/Node/Query 生命周期、Grammar、Capture、JNI/Native 边界、增量解析、解析调度与取消、结果版本校验、语法高亮数据生成，以及大文件解析降级和内存保护。不负责编辑器 View、文本编辑事务或 LSP 通信。

This is an intentionally empty bootstrap module. No implementation classes or speculative dependencies are added yet.
